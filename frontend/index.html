¿Cómo funciona con gRPC?
  1. Client streaming: el simulador del repartidor envía su ubicación al servidor gRPC cada segundo (SendLocations).
  2. Server streaming: el servidor gRPC reenvía cada ubicación a quien sigue el pedido (TrackOrder).
  3. Unaria: los datos del pedido se piden con GetOrder.
  4. Unaria: tu ubicación (o el punto que elijas) se envía con ChangeDestination; el servidor calcula la ruta por las calles.
  5. El navegador recibe todo a través de un gateway Express (SSE), porque los navegadores no hablan gRPC nativo.
